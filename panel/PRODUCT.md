# PRODUCT — actdsh 校验面板

## 它是什么

actdsh 是 deepseek-harness 官方桌面版的第三方 Windows 便携 zip 发行渠道。官方桌面
只经 download.deepseek.com 分发，GitHub Releases 不放产物。本面板是这个发行链路的
独立校验视图：把「探针可达性 + sha512 门禁 + 构建清单」三类证据摆在一起，让人能在
不信任任何单一环节的前提下自行判断某个产物是否可信、是否落后上游。

## 面板内容

- 状态横幅：聚合可达通道数与总体结论。
- 通道卡：每条官方通道一张 service 卡，给出当前版本、发布 run、发布时间与版本漂移
  条带；落后的通道以颜色 + 落后版本数文字双重标示。
- sha512 门禁：具体 run、具体哈希前缀、可点的产物链接。
- 构建清单：钉死依赖数与独立补充依赖的可核对明细。

所有状态与动作语义用 SVG 图标 + 文字双重表达，不单独靠颜色承载语义。

## 数据来源

面板数据取自每日探针与构建记录的真实快照（见 src/data/verification.ts），可逐项
核对到具体的发布 run 与产物哈希。
